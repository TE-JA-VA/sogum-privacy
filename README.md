# 소금항아리 개인정보 처리방침

시행일 2026년 9월 25일 · 적용 앱: 소금항아리 (iPhone, iPad, Mac)

웹 페이지 버전: https://te-ja-va.github.io/sogum-privacy/

**요약:** 소금항아리 앱은 개인정보를 수집하지 않습니다. 계정도, 광고도, 분석 도구도 없습니다. 즐겨찾기와 설정은 오직 사용자의 기기 안에만 저장됩니다.

## 1. 수집하는 개인정보

없습니다. 이름, 이메일, 전화번호, 위치, 연락처, 기기 식별자 등 어떤 개인정보도 수집·저장·전송하지 않습니다. 회원 가입이나 로그인이 없습니다.

## 2. 기기 안에만 저장되는 정보

- 즐겨찾기: 사용자가 ♥로 저장한 묵상 글, 카드 이미지, 음성 파일
- 설정: 글꼴, 글자 크기, 읽어주기 속도·목소리, 마지막으로 듣던 위치
- 임시 파일: 빠른 표시를 위해 내려받은 글·이미지·음성 (앱을 지우면 함께 삭제됨)

이 정보는 사용자의 기기를 떠나지 않으며, 개발자를 포함해 누구에게도 전송되지 않습니다.

## 3. 인터넷 연결

앱은 다음 서버에서 콘텐츠를 내려받기만 합니다. 이때 일반적인 웹 접속과 마찬가지로 해당 서버가 접속 IP 주소를 기록할 수 있으며, 이는 각 서버 운영자의 정책을 따릅니다. 앱은 어떤 사용자 식별 정보도 함께 보내지 않습니다.

- 생활성서사 (biblelife.co.kr): 묵상 글과 카드 이미지
- GitHub (github.com): 미리 만들어 둔 읽어주기 음성 파일

## 4. 기기 권한

- 사진 추가 권한: 사용자가 카드 이미지를 "사진에 저장"할 때만 요청합니다. 앱은 사진 보관함을 읽을 수 없고, 사용자가 직접 저장을 누른 이미지 한 장만 추가합니다.

그 밖의 권한(위치, 마이크, 카메라, 연락처, 알림 등)은 사용하지 않습니다.

## 5. 제3자 제공·광고·분석

개인정보를 제3자에게 제공하지 않습니다. 광고, 사용 통계·분석 도구, 충돌 보고 도구를 넣지 않았습니다.

## 6. 아동의 개인정보

이 앱은 어떤 사용자로부터도 개인정보를 수집하지 않으므로, 아동의 개인정보도 수집하지 않습니다.

## 7. 콘텐츠 출처

묵상 글과 카드 이미지의 저작권은 월간 생활성서 '소금항아리'(생활성서사)에 있습니다. 앱은 모든 글에 원문 링크를 표시합니다.

## 8. 방침 변경

내용이 바뀌면 이 페이지를 갱신하고 시행일을 고칩니다.
